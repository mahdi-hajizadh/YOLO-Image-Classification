# YOLO Image Classifier

An image classification application built with Python,
Ultralytics YOLO26 and Streamlit.

## Features

- Image upload (JPG, JPEG, PNG)
- AI-powered image classification
- Top-5 predictions
- Confidence scores
- Interactive web interface

## Technologies

- Python
- YOLO26 Classification
- Ultralytics
- Streamlit
- Pillow
